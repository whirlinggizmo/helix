# Benchmarks: web sizes

Generated by `tools/measure_sizes.py --write` from `benchmarks.json`, the baseline CI holds to (`--check`, in `helix.py test`: a rung more than 1% and 1 KB larger, gzipped, fails). Each library has a ladder of programs on it and what it sits on, each constructing only what it uses. Every rung is a release browser build (`-dce full`, the analyzer), its JavaScript unminified, as Haxe alone writes it; sizes in KB.

Measured from 7aef88a 2026-10-29 with Haxe 4.3.7.
