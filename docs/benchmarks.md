# Benchmarks: web sizes

Generated by `tools/measure_sizes.py --write` from `benchmarks.json`, the baseline CI holds to (`--check`, in `helix.py test`: a rung more than 1% and 1 KB larger, gzipped, fails). Each library has a ladder of programs on it and what it sits on, each constructing only what it uses. Every rung is a release browser build (`-dce full`, the analyzer), its JavaScript unminified, as Haxe alone writes it; sizes in KB.

Measured from 8ab28a7 2026-11-04 with Haxe 4.3.7.

## helix-raylib

Programs written in raylib on helix-raylib (`engines/raylib/tests/sizes/`), each adding one feature to the one before, from a window cleared each frame: what a feature costs through raylib's API is its row's increment, gzip; brotli in brackets. Against the services' ladder this is what the familiar API costs (DECISIONS 15): helix-raylib's window brings its time, the screen (with the saves it keeps its state in) and the keyboard, so its first rung holds them; the rest (the assets its files load through, the image decoder, the dropped files) comes with the functions that need it (DECISIONS 30). Each rung's `@:adds` names what it adds. Its 3D starts with a cube made in memory (GenMeshCube, LoadModelFromMesh), drawn unlit with a camera: the 3D drawing alone, so the glTF rung after it is the reader's own cost. helix-raylib's bytes are counted by source file: raylib's modules (R*) and its internals, its facade and structs as raylib. The last two rungs are its high-water marks. The game is what a real game uses, one file format of each kind (a skinned, blended glTF model, PNG textures, a TTF font, WAV sounds and Ogg music, every input, a save, a shader and a render texture). The kitchen sink calls every function of `Raylib`, `Raymath`, `Rlgl` and `helix.raylib.extras` that compiles, written as the program builds (its `Everything.hx`), and every reader by a constant name of each extension, so nothing of helix-raylib is left out: it is the comparison point for whole-library sizes, such as an Emscripten build of raylib exporting everything.
