# Lanternholm

A floating island under a turning sky, its trees to plant and its nubbins to poke, as three.js draws it. `spec.md` is the game,
naming no engine; `grading.md` its items a run is graded on, from screenshots at set times and places beside `reference/`, the
original's. `native/`, `native-c/` and `three/` hold the briefs for helix-raylib with the extras, raylib C and three.js, and
`../../tools/run_entrant.py --game` builds it in place of Wardens.
