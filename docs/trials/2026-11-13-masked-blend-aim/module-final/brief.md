- **How raylib looks here.** This is raylib 5.5 in Haxe. Each raylib header is a class in package `helix.raylib`: `raylib.h` is `helix.raylib.Raylib`, and `import helix.raylib.Raylib.*;` brings its functions, constants and colors in unqualified, as raylib names them. `raymath.h` is `Raymath` and `rlgl.h` is `Rlgl`. raylib's structs are classes of the same names and fields in `helix.raylib`. Write it as you would write a raylib program.
