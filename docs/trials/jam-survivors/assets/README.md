# Wardens assets

`ui/` and `sound/` are generated by `../gen_assets.py` (run `python3 gen_assets.py` from the jam directory). They are the trial's
own art and sounds, with no third-party content: `ui/panel.png`, `ui/button.png`, `ui/icons.png`, `ui/slices.txt`, `ui/icons.txt`,
`sound/slash.wav`, `shot.wav`, `hit.wav`, `gem.wav`, `level.wav` and `sound/music.ogg`.

`characters/` is not kept here. It is copied in at the run from
`/home/rknopf/projects/github/whirlinggizmo/helix/examples/assets/models/modular-women/` (Quaternius, Ultimate Modular Women, CC0).
