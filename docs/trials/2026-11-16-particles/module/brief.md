Write the program in `{DIR}/task.md` in Haxe, using **raylib 5.5's API**.

- **How raylib looks here.** This is raylib 5.5 in Haxe. Each raylib header is a class in package `helix.raylib`: `raylib.h` is `helix.raylib.Raylib`, and `import helix.raylib.Raylib.*;` brings its functions, constants and colors in unqualified, as raylib names them. `raymath.h` is `Raymath`, `rlgl.h` is `Rlgl`, and the examples' `rlights.h` is `Rlights`. raylib's structs are classes of the same names and fields in `helix.raylib` (`import helix.raylib.*;`). Write it as you would write a raylib program.
- **Extras.** helix-raylib adds calls raylib hasn't, in `helix.raylib.extras`. Use two of them. The Particles extra (`import helix.raylib.extras.Particles.*;`) makes every effect: its page is `{DIR}/docs/api/extras-particles.md`. The Lighting extra (`import helix.raylib.extras.Lighting.*;`) lights the camp: its page is `{DIR}/docs/api/extras-lighting.md`. Learn them from their pages.
- **Docs:** raylib 5.5's own headers are in `{DIR}/docs/include/` and its C examples in `{DIR}/docs/examples/`. helix-raylib's page for its types is `{DIR}/docs/api/types.md`. Read them as you need. Read nothing else about the library: no library sources, no other documentation, no web. Where it differs from raylib in C, the compiler tells you.
- **Assets:** the camp's models and the font are in `{DIR}/assets/`, named by their paths from this directory, as `"assets/models/barrel.glb"`. Any other texture you make in code.
- **Building:** in `{DIR}`, `haxe build.hxml` builds the program natively as `native/Main`. Don't change `build.hxml`. Build as often as you like.
- **Running:** `./native/Main [arguments]` from `{DIR}` runs it, passing it the arguments (as `--quit_after_frame=300`, which quits it after that frame). It runs on a display of its own, never on the desktop, with no sound. What it logs is printed. Look at `shot.png` to see it.
- **Writing:** write to `{DIR}` only: `Main.hx` and what it imports, then `NOTES.md` with each compile error you hit, in order, and what you changed for it; each warning the program logged and what you changed for it; each place you were left guessing what a Particles or Lighting call or field does, and what you guessed; and anything you'd change in the Particles extra.
