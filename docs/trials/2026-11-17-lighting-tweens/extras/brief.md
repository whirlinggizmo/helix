Write the program in `{DIR}/task.md` in Haxe, using **raylib 5.5's API**.

- **How raylib looks here.** This is raylib 5.5 in Haxe. Each raylib header is a class in package `helix.raylib`: `raylib.h` is `helix.raylib.Raylib`, and `import helix.raylib.Raylib.*;` brings its functions, constants and colors in unqualified, as raylib names them. `raymath.h` is `Raymath` and `rlgl.h` is `Rlgl`. raylib's structs are classes of the same names and fields in `helix.raylib` (`import helix.raylib.*;`). Write it as you would write a raylib program.
- **Extras.** helix-raylib adds calls raylib hasn't, in `helix.raylib.extras`. Two are given here. The Lighting extra (`import helix.raylib.extras.Lighting.*;`) has lit shaders and lights: its page is `{DIR}/docs/engines/raylib/api/extras-lighting.md`. The tweens (`import helix.raylib.extras.tweens.*;`) move a value over time along an easing curve: their page is `{DIR}/docs/engines/raylib/api/extras-tweens.md`, and the types it names are in `{DIR}/docs/libs/tweens/api/types.md` and `{DIR}/docs/libs/math/api/types.md`. Read the ones you need, and use what helps.
- **Docs:** raylib 5.5's own headers are in `{DIR}/docs/include/` and its C examples in `{DIR}/docs/examples/`. helix-raylib's page for its types is `{DIR}/docs/engines/raylib/api/types.md`. Read them as you need. Read nothing else about the library: no library sources, no other documentation, no web. Where it differs from raylib in C, the compiler tells you.
- **Building:** in `{DIR}`, `haxe build.hxml` builds the program natively as `native/Main`. You may add to `build.hxml`. Build as often as you like.
- **Running:** `./native/Main [arguments]` from `{DIR}` runs it, passing it the arguments (as `--quit_after_frame=300`, which quits it after that frame). It runs on a display of its own, never on the desktop, with no sound. What it logs is printed. Look at `shot.png` to see it.
- **Writing:** write to `{DIR}` only: `Main.hx` and what it imports, its shaders, and `build.hxml`, then `NOTES.md` with each compile error you hit, in order, and what you changed for it; each warning the program logged and what you changed for it; each thing you reached for that wasn't there, and what you did instead; each place you were left guessing what a Lighting or tween call or field does, and what you guessed; and what you wrote yourself that an extra could have done, and why.
