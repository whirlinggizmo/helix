# helix.adapter and helix.profile

The platform code: one adapter an API behind each contract, and the profiles that choose them (ARCHITECTURE.md). A game writes against the contracts, never these.

[Back to the index](README.md)

- **Sdl3AudioAdapter** (`src/helix/adapter/audio/sdl3/Sdl3AudioAdapter.hx`): IAudio natively over an SDL3 audio stream into the default playback device, mixed by the shared mixer; SDL converts to the device's format and rate.
- **AudioBridge** (`src/helix/adapter/audio/sdl3/internal/AudioBridge.hx`): Built with the app by hxcpp: an SDL3 audio stream into the default playback device feeding the shared mixer (shared/mixer.c); linked with the SDL3 the host links (HELIX_SDL3_LIBRARY).
- **SokolAudioAdapter** (`src/helix/adapter/audio/sokol/SokolAudioAdapter.hx`): IAudio natively over sokol_audio (ALSA, WASAPI, AudioToolbox), mixed by the shared mixer.
- **AudioBridge** (`src/helix/adapter/audio/sokol/internal/AudioBridge.hx`): Built with the app by hxcpp: sokol_audio (ALSA on Linux, WASAPI on Windows, AudioToolbox on macOS) feeding the shared mixer (shared/mixer.c).
- **WebAudioAdapter** (`src/helix/adapter/audio/webaudio/WebAudioAdapter.hx`): IAudio in a browser over Web Audio: clips become AudioBuffers, streams are media elements routed through the audio graph, each voice a source through a gain and a stereo panner, its volume and pan changes ramped by setTargetAtTime (RAMP) and its pitch the source's playback rate. The page's first key or pointer press unlocks audio (browsers let it start only in a user gesture); the page losing focus or being hidden suspends it.
- **LibsndfileAudioDecoderAdapter** (`src/helix/adapter/audiodecoder/libsndfile/LibsndfileAudioDecoderAdapter.hx`): IAudioDecoder natively over libsndfile (Ogg Vorbis and Opus, MP3; mixed down and resampled to mono at 44100 Hz in its C), each decode on a worker thread.
- **LibsndfilePcmFiles** (`src/helix/adapter/audiodecoder/libsndfile/LibsndfilePcmFiles.hx`): Audio files natively over libsndfile (WAV, Ogg Vorbis and Opus, MP3), read as mono at 44100 Hz for a native output to stream. A download is copied into the codec's memory (a file's length taken at its open), the rest of it as it arrives, at each read; the C reads it through libsndfile's virtual I/O. An Ogg file opened before its end plays to the end of its stream (libsndfile can't learn its length without its last bytes); an MP3 without a Xing or Info header opens only once whole (libsndfile scans it for its length).
- **CodecBridge** (`src/helix/adapter/audiodecoder/libsndfile/internal/CodecBridge.hx`): Built with the app by hxcpp: libsndfile: HELIX_CODEC_LIBRARY when a build names it (tools/native_build.py: the system's on Linux, the pinned release on Windows, Homebrew's on macOS); else, on Linux, the system's by soname, so a game built with only -lib helix links it.
- **WebAudioDecoderAdapter** (`src/helix/adapter/audiodecoder/webaudio/WebAudioDecoderAdapter.hx`): IAudioDecoder in a browser: decodeAudioData on an OfflineAudioContext at 44100 Hz (no user gesture needed; it resamples), its channels mixed down to mono.
- **DownloadExportAdapter** (`src/helix/adapter/export/download/DownloadExportAdapter.hx`): IExport in a browser: the file is downloaded, as a link with the download attribute does it (the browser may ask where, or keep it in its downloads). The page can't know whether the user kept it; Exported says only that the download began.
- **FileSystemExportAdapter** (`src/helix/adapter/export/filesystem/FileSystemExportAdapter.hx`): IExport natively: the file is written into a directory (made when first needed), through a temporary file renamed over it, so a file there is never half written.
- **Sdl3GpuGraphicsAdapter** (`src/helix/adapter/graphics/sdl3gpu/Sdl3GpuGraphicsAdapter.hx`): IGraphics on SDL_GPU for native hxcpp builds under the SDL3 host: Vulkan, Direct3D 12 or Metal, whichever SDL picks for the system (SDL_GPU_DRIVER chooses another); programs from a ShaderSource's SDL_GPU dialects (built with -D helix_sdl3_gpu).
- **GraphicsBridge** (`src/helix/adapter/graphics/sdl3gpu/internal/GraphicsBridge.hx`): Built with the app by hxcpp: SDL_GPU (Vulkan, Direct3D 12 or Metal, as SDL picks) presenting to the SDL3 host's window (adapter/shared/ surface.h), linked with the SDL3 the host links (HELIX_SDL3_LIBRARY); the shared graphics calls (shared/graphics.h, GraphicsDeviceBridge) and its own: setup, shutdown, and programs in the device's dialect.
- **SokolGraphicsAdapter** (`src/helix/adapter/graphics/sokol/SokolGraphicsAdapter.hx`): IGraphics on sokol_gfx for native hxcpp builds, drawing GL 4.1 in the host's context: programs from a ShaderSource's GLSL 410.
- **GraphicsBridge** (`src/helix/adapter/graphics/sokol/internal/GraphicsBridge.hx`): Built with the app by hxcpp: sokol_gfx on GL 4.1 core, in whichever native host's GL context (its size from adapter/shared/surface.h), and sokol_log; the shared graphics calls (shared/graphics.h, GraphicsDeviceBridge) and its own: setup, shutdown and programs from GLSL 410.
- **WebGL2GraphicsAdapter** (`src/helix/adapter/graphics/webgl2/WebGL2GraphicsAdapter.hx`): IGraphics on a canvas's WebGL2 context: raw browser API calls only. It builds whatever program it is given (a ShaderSource's GLSL ES) and makes whatever pipeline it is described (a PipelineDesc); it knows no program, layout or pipeline of HeliX's own.
- **DomHostAdapter** (`src/helix/adapter/host/dom/DomHostAdapter.hx`): The browser host: the page's canvas (id "canvas") and its window, a requestAnimationFrame loop, the page's clock, and options from the URL query. An error the page doesn't catch, or a lost graphics context, stops the frames and says so in the element with id "status".
- **DomWindow** (`src/helix/adapter/host/dom/DomWindow.hx`): The page is the window: its title is the document's, its size the viewport's, and fullscreen is the canvas's. A page can't move or size its window, or choose a monitor; it sees one screen.
- **Sdl3HostAdapter** (`src/helix/adapter/host/sdl3/Sdl3HostAdapter.hx`): The native host through SDL3: one window and its frame loop, the window with a GL 4.1 context for sokol_gfx or without one for SDL_GPU. One per program.
- **HostBridge** (`src/helix/adapter/host/sdl3/internal/HostBridge.hx`): Built with the app by hxcpp: the SDL3 window, its GL 4.1 context (or none, for SDL_GPU) and the frame loop, linked with HELIX_SDL3_LIBRARY (tools/sdl3.py: the system's SDL3 of 3.4.18 or newer, or the pinned one built or fetched into build/deps), compiled against vendor/sdl3's headers. On Linux, Xlib too, to ask whether X is XWayland; on Windows, DWM's, to wait on the compositor.
- **SokolHostAdapter** (`src/helix/adapter/host/sokol/SokolHostAdapter.hx`): The native host through sokol_app: one window and its frame loop (X11 and GLX, Win32 and WGL, Cocoa). One per program.
- **HostBridge** (`src/helix/adapter/host/sokol/internal/HostBridge.hx`): Built with the app by hxcpp: The sokol_app window and loop, and sokol_app_utils' window and display calls: X11 and GLX on Linux, Win32 and WGL on Windows, Cocoa on macOS (compiled as Objective-C there through host_macos.m, as hxcpp picks a file's language by its extension).
- **FetchApiHttpAdapter** (`src/helix/adapter/http/fetchapi/FetchApiHttpAdapter.hx`): IHttp in a browser over fetch(): the body read as it arrives, abort through an AbortController. A request with conditional headers (If-None-Match, If-Modified-Since) to another origin would need a CORS preflight, so there they're left out and the browser revalidates its own copy instead (cache "no-cache"), answering 200.
- **HaxeHttpAdapter** (`src/helix/adapter/http/haxehttp/HaxeHttpAdapter.hx`): IHttp natively over haxe.Http, a worker thread a transfer: http and https URLs only (others end with a failure), noCache has nothing to bypass, and an abort stops the transfer at its next part of the body (not while it connects).
- **CanvasImageDecoderAdapter** (`src/helix/adapter/imagedecoder/canvas/CanvasImageDecoderAdapter.hx`): IImageDecoder in a browser: the page's own decoder (createImageBitmap, without colour conversion or premultiplying), read back as RGBA through an OffscreenCanvas, which stores pixels premultiplied: a partly transparent pixel may come back a level or two from the file.
- **StbImageDecoderAdapter** (`src/helix/adapter/imagedecoder/stb/StbImageDecoderAdapter.hx`): IImageDecoder natively over stb_image, each decode on a worker thread.
- **ImageBridge** (`src/helix/adapter/imagedecoder/stb/internal/ImageBridge.hx`): Built with the app by hxcpp: stb_image.
- **DomInputSourceAdapter** (`src/helix/adapter/inputsource/dom/DomInputSourceAdapter.hx`): Browser input: keys and typed text from the window; mouse buttons, moves, fingers and wheel from the canvas, in its framebuffer pixels; focus from the window's focus and the page's visibility; gamepads read at poll(), in the W3C standard layout.
- **Sdl3InputSourceAdapter** (`src/helix/adapter/inputsource/sdl3/Sdl3InputSourceAdapter.hx`): Native input through SDL3: its window's events (keys by physical position, the pointer, text, touch, focus) and its gamepads, through its controller database, connected and disconnected while running.
- **InputBridge** (`src/helix/adapter/inputsource/sdl3/internal/InputBridge.hx`): Built with the app by hxcpp: the shared input queue (shared/input.c), which an SDL event watch fills with keys, the pointer, text, touch and focus, and SDL's gamepads (its controller database, hot-plugging); linked with the SDL3 the host links (HELIX_SDL3_LIBRARY).
- **SokolInputSourceAdapter** (`src/helix/adapter/inputsource/sokol/SokolInputSourceAdapter.hx`): Native input through sokol_app: the sokol host's window events, and the OS's gamepads (evdev on Linux, XInput on Windows, none on macOS).
- **InputBridge** (`src/helix/adapter/inputsource/sokol/internal/InputBridge.hx`): Built with the app by hxcpp: the shared input queue (shared/input.c), which the sokol host's events fill, and gamepads: evdev on Linux, XInput on Windows (loaded at run time), none on macOS.
- **GraphicsDeviceBridge** (`src/helix/adapter/shared/GraphicsDeviceBridge.hx`): The graphics calls every native graphics adapter's C implements (graphics.h), built by whichever graphics adapter the program links (its own GraphicsBridge).
- **IPcmFiles** (`src/helix/adapter/shared/IPcmFiles.hx`): Audio files read as mono 32-bit float PCM at 44100 Hz, a part at a time: what a native output streams from, supplied by a codec adapter. Callable from any thread, a handle at a time; a download's (openArriving) from the host thread only, as its source is written there.
- **InputQueueBridge** (`src/helix/adapter/shared/InputQueueBridge.hx`): The shared input queue's C (input.h), built by whichever input adapter the program links (its own InputBridge): the events queued since the last poll, and the gamepads.
- **Mailbox** (`src/helix/adapter/shared/Mailbox.hx`): How a native adapter's threads hand work back to the host thread: post from any thread, deliver on the host thread (the adapter's poll).
- **MixerBridge** (`src/helix/adapter/shared/MixerBridge.hx`): The shared mixer's C (audio.h: mixer.c, and the output's availability, rate and channels), built by whichever audio adapter the program links (its own AudioBridge).
- **NativeAudio** (`src/helix/adapter/shared/NativeAudio.hx`): IAudio natively, for either output (sokol_audio's or SDL3's): mono voices at 44100 Hz mixed to stereo (pan, pitch, volume ramps), 16 voices, 32 clips, mixed in C (mixer.c). Streams play stored files and downloads as they arrive (a remote URL fails: AudioResources downloads it, playsUrls being false), read through files (a codec adapter's), each voice kept 88200 frames (2 s) ahead by poll for up to 2 ms a frame, so a frame stalled under that plays on: how a push-based output plays a file as it's read. A download opens once 64 KiB have arrived (or the whole, when it's smaller), tried again each time what has arrived doubles while its codec can't open it yet; a voice decodes it only while it has arrived 64 KiB past the codec's position (or whole), as the codec takes a short read for the end, and otherwise waits, its 2 s covering a slow connection's gaps; a download that fails plays to where it stopped, then ends as at the end of its file.
- **NativeGraphics** (`src/helix/adapter/shared/NativeGraphics.hx`): What either native graphics adapter (sokol_gfx's, SDL_GPU's) does the same: IGraphics passed to the C of shared/graphics.h as plain data (GraphicsDeviceBridge), which each adapter's own C implements; it knows no program, layout or pipeline of HeliX's own. A call the C refuses throws. An adapter sets its C up, builds programs from the dialect its C takes (createShader) and shuts down.
- **NativeHost** (`src/helix/adapter/shared/NativeHost.hx`): What either native host (sokol_app's or SDL's) does the same: the frame loop's callbacks, haxe.Timer's clock, the window (NativeWindow) and options from HELIX_* environment variables. A host adapter opens its window and runs its loop (start) and quits.
- **NativeInputSource** (`src/helix/adapter/shared/NativeInputSource.hx`): What either native input source (sokol's or SDL3's) does the same: the window's queued events reported in order at poll (so a press and release in one frame keep both edges), then the gamepads, all through the shared queue (input.h). An input adapter sets its source up, moves it on each poll (pollSource) and shuts it down.
- **NativeWindow** (`src/helix/adapter/shared/NativeWindow.hx`): The desktop window of either native host (sokol_app's or SDL's), through the C each implements (window.h). Moves are refused where the compositor places windows (Wayland, XWayland).
- **ReplaceBridge** (`src/helix/adapter/shared/ReplaceBridge.hx`)
- **WindowBridge** (`src/helix/adapter/shared/WindowBridge.hx`): The desktop window's C (window.h), implemented by whichever native host the program links; built by that host's own bridge.
- **FileSystemStoreAdapter** (`src/helix/adapter/store/filesystem/FileSystemStoreAdapter.hx`): IStore natively: files under a root directory, a key as a relative path, each operation on a worker thread; a write goes to a sibling temporary file renamed over the old one, so a reader never sees half a file. A lease is the file's path, with nothing to release.
- **IndexedDbStoreAdapter** (`src/helix/adapter/store/indexeddb/IndexedDbStoreAdapter.hx`): IStore in a browser: Blobs in an IndexedDB database, a lease a Blob URL (released by revoking it). Operations asked before the database opens wait for it.
- **DomTestHarnessAdapter** (`src/helix/adapter/testharness/dom/DomTestHarnessAdapter.hx`): The browser's test harness: a published result is window.result, which a check's headless browser reads.
- **StdioTestHarnessAdapter** (`src/helix/adapter/testharness/stdio/StdioTestHarnessAdapter.hx`): The native test harness: a published result is a JSON line on stdout, also written to the file HELIX_RESULT names.
- **Sdl3GLProfile** (`src/helix/profile/Sdl3GLProfile.hx`): The desktop through SDL3, drawing with GL (the `sdl3-gl` backend): an SDL window, its input and gamepads, sokol_gfx on GL 4.1 in its context, an SDL audio stream with libsndfile, haxe.Http and files, stb_image.
- **Sdl3GpuProfile** (`src/helix/profile/Sdl3GpuProfile.hx`): The desktop through SDL3, drawing with SDL_GPU (the `sdl3-gpu` backend): an SDL window, its input and gamepads, SDL_GPU (Vulkan, Direct3D 12 or Metal) presenting to it; built with -D helix_sdl3_gpu, so the framework's programs carry SDL_GPU's dialects; an SDL audio stream with libsndfile, haxe.Http and files, stb_image.
- **SokolGLProfile** (`src/helix/profile/SokolGLProfile.hx`): The desktop through sokol, drawing with GL on every system (the `sokol-gl` backend): a sokol_app window (X11 and GLX, Win32 and WGL, Cocoa), sokol_gfx on GL 4.1 core, sokol_audio with libsndfile, evdev gamepads on Linux and XInput on Windows, haxe.Http and files, stb_image.
- **WebGL2Profile** (`src/helix/profile/WebGL2Profile.hx`): The browser on WebGL2 (the `webgl2` backend): the page's host and canvas, Web Audio, fetch, IndexedDB and the page's image decoder.
