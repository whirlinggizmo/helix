# API reference

Every public type of each library, from the code's doc comments: generated by `tools/gen_apidoc.py`; `python3 tools/gen_apidoc.py --check` fails when it's stale. A file a package, each type with its public members. Every type here is on both Haxe targets, js (the browser) and cpp (native), but the adapters, each for one target, which a program constructs by name; a library's own types beneath (@:noCompletion) are left out.

- [`helix.math`](math.md): Bounds2D, Bounds3D, Curve, CurveKind, Interpolate, Point2D, Point3D, Random, Trig
- [`helix.platform.adapters`](platform-adapters.md): Sdl3MixerAudioAdapter, WebAudioAdapter, Sdl3MixerAudioDecoderAdapter, WebAudioDecoderAdapter, DomEventsAdapter, DomEventsAdapterOptions, Sdl3EventsAdapter, DownloadExportAdapter, FileSystemExportAdapter, FileSystemExportAdapterOptions, BrowserFileSystemAdapter, BrowserFileSystemAdapterOptions, NativeFileSystemAdapter, NativeFileSystemAdapterOptions, Sdl3GpuGraphicsAdapter, SokolGraphicsAdapter, WebGl2GraphicsAdapter, WebGl2GraphicsAdapterOptions, FetchApiHttpAdapter, HaxeHttpAdapter, CanvasImageDecoderAdapter, StbImageDecoderAdapter, DomSystemAdapter, Sdl3SystemAdapter, DomWindowAdapter, DomWindowAdapterOptions, Sdl3WindowAdapter, Sdl3WindowAdapterOptions, Sdl3WindowGraphics
- [`helix.platform.tools`](platform-tools.md): ShaderCompiler
- [`helix.platform`](platform.md): BlendMode, ClipFlip, Color, CullFace, DepthTest, Device, Event, Filter, GraphicsUnavailableException, GrowingSource, IAudio, IAudioDecoder, IEvents, IExport, IFileSystem, IGraphics, IHttp, IImageDecoder, IPollable, ISystem, IWindow, Key, MouseButton, Orientation, PadAxis, PadButton, PipelineDesc, Primitive, Sampling, SdlGpuStages, ShaderBlock, ShaderSource, ShaderStages, ShaderTexture, StreamSource, TextureFormat, VertexAttribute, VertexBuffer, Wrap
- [`helix.services.assets`](services-assets.md): AssetCacheMode, AssetSource, Assets, AssetsOptions
