# API reference

Every public type of each library, from the code's doc comments: generated by `tools/gen_apidoc.py`; `python3 tools/gen_apidoc.py --check` fails when it's stale. A file a package, each type with its public members. Every type here is on both Haxe targets, js (the browser) and cpp (native); the adapters, which a program constructs by name for its target, and a library's own types beneath (@:noCompletion) are left out.

- [`helix.log`](log.md): Log, LogLevel
- [`helix.math`](math.md): Bounds2D, Bounds3D, Curve, CurveKind, Interpolate, Point2D, Point3D, Random, Trig
- [`helix.platform`](platform.md): BlendMode, ClipFlip, Color, CullFace, DepthTest, Device, Event, Filter, GraphicsUnavailableException, GrowingSource, IAudio, IAudioDecoder, IEvents, IExport, IFileSystem, IGraphics, IHttp, IImageDecoder, IPollable, ISystem, IWindow, Key, MouseButton, Orientation, PadAxis, PadButton, PipelineDesc, Primitive, Sampling, SdlGpuStages, ShaderBlock, ShaderSource, ShaderStages, ShaderTexture, StreamSource, TextureFormat, VertexAttribute, VertexBuffer, Wrap
