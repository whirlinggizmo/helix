# API reference

Every public type of each library, from the code's doc comments: generated by `tools/gen_apidoc.py`; `python3 tools/gen_apidoc.py --check` fails when it's stale. A file a package, each type with its public members. Every type here is on both Haxe targets, js (the browser) and cpp (native), but the adapters, each for one target, which a program constructs by name; a library's own types beneath (@:noCompletion) are left out.
